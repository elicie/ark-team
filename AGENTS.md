# Repository Instructions

## CodeGraph

- When starting source work, check whether `.codegraph/` exists at the repository root.
- If it is missing and the `codegraph` CLI is available, run `codegraph init .` before making source changes.
- During coding work, use `codegraph` when it can clarify structure, dependencies, callers/callees, impact, affected tests, or task-specific context.
- Before committing source work, run `codegraph sync .` from the repository root.
